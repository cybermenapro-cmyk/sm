# Changelog

## 0.1.0-beta - initial prototype

- Added a reference interpreter and `.sm` source format.
- Added dynamic variables, lists, fixed arrays, objects, and native size values.
- Added temporary and persistent data blocks.
- Added sandboxed file and directory operations.
- Added storage preview plans, SHA-256 verification, recoverable trash, and quota reporting.
- Added read-only device capacity reporting.
- Added SU permission-request syntax without host privilege escalation.
